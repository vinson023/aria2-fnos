| 项目 | 内容 |
| --- | --- |
| 当前状态 | 已确认（2026-08-27） |

## D-002 首发 CPU 架构

| 项目 | 内容 |
| --- | --- |
| 当前状态 | 已确认（2026-08-27） |
| 建议方案 | 先发布 x86 包，验证稳定后再发布 ARM 包 |

## D-003 下载目录与授权策略

| 项目 | 内容 |
| --- | --- |
| 当前状态 | 已确认（2026-08-27） |
| 建议方案 | 默认创建应用共享目录，同时允许管理员通过飞牛授权选择其他目录 |
| 保守方案 | 第一版只允许应用共享目录 |
| 影响 | 决定 `config/resource`、配置向导、Web SDK 目录选择、路径校验和卸载保留规则 |
| 安全要求 | 任何目录都必须经过飞牛共享目录或用户授权；禁止按字符串直接信任 `/vol*` 路径 |
| 确认后动作 | 固定数据目录模型、授权 API 和 Aria2 `dir` 配置生成方式 |

## D-004 首版是否包含移动/归档

| 项目 | 内容 |
| --- | --- |
| 当前状态 | 已确认（2026-08-27） |
| 建议方案 | 首版包含可选归档模式，但默认关闭；目标目录必须单独授权 |
| 简化方案 | 首版只实现下载和清理，移动/归档延后 |
| 影响 | 决定是否打包 `move.sh`、是否增加归档目录向导、跨目录移动的空间和权限提示 |
| 安全要求 | 归档操作必须限制在已授权目标目录，不能覆盖任意系统路径 |
| 确认后动作 | 固定 `script.conf` 字段、配置 UI 和验收用例 |
