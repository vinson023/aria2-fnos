# 开发计划

## 阶段一：初始化与确认

本阶段已完成项目规范、项目上下文、需求分析、技术栈、架构、目录职责、参考基线、行为矩阵、许可证计划和本开发计划。D-001 至 D-005 已于 2026-08-27 确认，现进入 Phase 2。

完成条件：产品范围和待确认问题得到确认。已完成。

阶段一持续期间，使用 `docs/requirements-traceability.md` 检查新增需求是否已
进入设计、开发阶段和未来验收证据；未确认的产品决策不得被实现阶段默认填充。
使用 `docs/phase1-decisions.md` 收集五项发布前决策；五项全部确认后才允许进入 Phase 2。
使用 `docs/phase1-review.md` 复核阶段一证据和禁止越界事项；审查判定为未完成时，
不得创建 FPK 源目录或任何业务运行文件。
使用 `docs/security-model.md` 复核网关、进程、文件和端口边界，避免把安全假设留到实现阶段。
使用 `docs/fnos-integration-matrix.md` 固定 manifest、统一网关、Web SDK、资源声明和 Aria2 RPC 的职责边界。

### 阶段一文档冻结与变更规则

- 阶段一交付物包括中文项目说明、需求分析、技术栈、架构、目录结构、开发计划、
  需求追踪、参考基线、安全模型、飞牛集成矩阵、上游行为矩阵、许可证计划、SDK 契约
  和 ADR；这些文件共同构成后续实现的约束基线。
- 用户对产品范围的最新明确确认优先于摘要文档；涉及端口、权限、目录、网关、运行时
  依赖或发布架构的变化，必须先更新确认记录、相关 ADR 和 `PROJECT_CONTEXT.md`。
- 需求追踪矩阵必须同步更新受影响的实现阶段和验收证据；不能只修改 README 或单个
  设计文件而留下未追踪需求。
- 离线参考资料只用于取证，不会自动批准上游功能；上游能力纳入产品前必须经过安全、
  许可证和架构复核。
- 阶段状态只有在存在可复核的命令输出、测试记录或设备验证证据时才能更新为“已完成”。

## 阶段二：打包基础（已完成）

已创建原生 fnpack 项目、manifest、图标、权限/资源声明、生命周期脚本和安装向导；配置向导字段已由生命周期脚本再次校验。`aria2.fpk` 可由 `fnpack` 构建并通过设备 App Center 安装。

完成条件：fnpack 校验通过，设备 App Center 已实际解析、安装并启动候选包。

## 阶段三：原生产物（已完成）

为选定架构创建 Aria2 Pro Core 与管理器的可复现构建，生成校验和、版本元数据、许可证和署名。

完成条件：Core、管理器和 AriaNg 版本/哈希/许可证已记录；x86_64 设备可执行，FPK 不含 Node/npm 运行时。

## 阶段四：服务生命周期与配置（已完成）

实现可重复执行的安装、配置初始化、启动、停止、状态、升级迁移和卸载数据保留逻辑；加入 `rpc_port` 与 `listen_port` 的校验、冲突检测、受控重启和监听验证。

完成条件：覆盖重复启停、端口修改/冲突、配置保留、卸载保留和设备启动的测试通过。

## 阶段五：网关与 UI（已完成）

实现 Unix Socket 管理器、管理员鉴权、受保护 RPC 代理、AriaNg 静态资源和飞牛 SDK 适配层。

已完成：Unix Socket 管理器、管理员 Header 校验、回环 RPC 代理、AriaNg 静态资源、单代理安全适配和设备侧静态资源/身份边界检查。

完成条件：已在设备 `0.1.11` 上验证桌面 iframe 的 `/app/aria2/` 目标、Socket 返回的
AriaNg 页面、管理员 RPC 代理和旧 Header 拒绝；固定 SDK Scope 与 `micro_app=true` 已生效。
目录选择器的成功、取消和无效/拒绝路径行为已取得设备或服务端证据。

## 阶段六：Aria2 Pro 行为（已完成）

实现会话恢复、DHT 持久化、Tracker 刷新、清理、可选归档、配置校验、日志和异常恢复。

已完成：完成回调的受限清理/可选归档、Tracker 的受限热更新及其设备重启持久化验证。
Tracker 仅作为不可信文本数据处理，不执行上游 `tracker.sh` 或任意远程脚本。

完成条件：error/removed、会话/DHT 重启恢复和 BT/DHT TCP/UDP 监听证据已整理进最终验收矩阵，
HTTP、FTP、BT、磁力和 Metalink 最小协议样本均已在测试机完成。

## 阶段七：设备验证与发布准备（已完成）

构建 FPK，在已授权测试机安装，验证完整生命周期与用户流程，并准备署名、许可证、变更日志和更新文档。

已完成：干净安装、启动/停止、卸载数据保留、候选包重装、端口和行为回归。

完成条件：飞牛应用中心手动安装至 `0.1.11`、版本迁移、数据保留、协议矩阵、桌面入口、
Socket 页面、最终发布物料和目录授权回调均已验证。
