# ADR-006：RPC 与 BT/DHT 端口可配置

## 状态

规划阶段已接受。

## 决策

第一版支持独立配置 Aria2 RPC 端口和 BT/DHT 监听端口，默认值分别为 `6800` 和
`6888`。端口配置写入持久配置，并通过安装向导和应用设置修改。

## 约束

- 仅接受合法用户态 TCP/UDP 端口。
- RPC 仍只绑定回环地址；修改 RPC 端口不意味着公开 RPC。
- BT/DHT 端口使用同一配置值，保持 TCP 与 UDP 一致。
- 保存前检查端口冲突和系统占用情况。
- 应用在变更后执行受控重启、监听验证和失败回滚/错误报告。

## 原因

不同 NAS、路由器、宿主服务和多实例部署可能已经占用默认端口；固定端口会导致
安装或启动失败，也无法满足用户的网络规划。

## 影响

AriaNg 适配层不能写死 `6800`，必须从应用管理器获取当前 RPC 配置。文档、健康
检查、日志和防火墙提示也必须展示实际端口。
