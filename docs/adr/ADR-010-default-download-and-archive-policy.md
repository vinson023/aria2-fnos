# ADR-010：默认下载目录与自动归档策略

## 状态

已接受，2026-09-04 起生效，对应发布版本 `0.1.90`（`0.1.89` 未设备安装，改动并入本版）。

第 1、2 条中「归档目录缺省时派生」的规则已由 `ADR-018` 收口为「归档目录恒定为
`<下载目录>/completed`，取消手工设置」，自 `0.2.0` 起生效；本 ADR 其余决策
（自动创建、边界校验、防套娃、运行期自愈）继续有效。

## 背景

`0.1.88` 之后用户提出三项默认值要求：默认下载目录固定为飞牛授权的数据共享目录，
默认归档目录为下载目录下的 `completed` 且不存在时自动创建，自动归档默认开启。
这把归档目录从“必须由用户显式选择的外部目录”改成“下载目录内部的派生目录”，
因此边界校验、目录创建时机和重复回调语义都需要重新定义。

## 决策

1. 默认值来源唯一。安装向导不再询问下载目录：`install_callback` 取
   `TRIM_DATA_SHARE_PATHS` 首项写入 `download_root`，派生 `archive_root`
   为其下的 `completed`，并同时写入 `archive_enabled: true` 与
   `special_mode: "move"`。环境变量缺失时三项同时降级为空与关闭，
   不虚构路径。共享目录本身由 `config/resource` 的 `data-share` 声明，
   应用不越出自己的授权范围。
2. 管理器仍保留同名派生逻辑（`normalizeConfig`），用于升级、旧配置和
   手工编辑的自愈：下载目录缺省时取共享目录首项，归档目录缺省时取下载目录下的
   `completed`，`special_mode` 缺省为 `move`，`archive_enabled` 始终由
   `special_mode` 派生。安装期写死默认值只是让“界面所见”和“磁盘所存”一致，
   运行期真值仍以归一化结果为准。
3. 归档目录自动创建分两处，且只补建最后一级。生命周期脚本以 root 运行时用
   `ensureConfiguredDirectories` 建目录，并把属主与权限对齐父目录（`0770` 加
   继承属主），使常驻的专属用户可以写入；回调以 `aria2` 用户运行时用
   `ensureArchiveDir` 在建目录前校验父目录边界。两处都不做递归创建，
   避免产生 root 属主、专属用户不可写的中间目录。创建失败不阻断启动，
   下一次回调会再次自愈。
4. 边界校验区分“等于授权根”和“越出授权根”。回调原有 `containedRoot` 明确拒绝
   相对结果为 `.`，用于任务文件是正确语义；但归档目录的父目录在新默认下恰好
   就是下载根本身，沿用同一函数会让归档在第一步静默失败。新增
   `pathWithinRoots` 专门用于父目录判断，允许“等于授权根”，同时仍然
   `EvalSymlinks` 解析后再比较，不削弱符号链接防护。
5. 归档目录位于下载目录内部后，必须防止套娃。默认布局下
   `archive_root` 是 `download_root` 的子目录，重复回调或用户把任务直接下到
   `completed` 时，再移动一次会得到 `completed/completed/...`。因此
   `archive` 在解析出归档根之后增加一跳判定：任务文件已位于归档根内即视为
   已归档，直接返回成功且不再移动。该判定只跳过，不放松任何边界校验。
6. 界面文案随语义更新但不重建前端。归档目录与归档开关的说明来自
   `www/langs/zh_Hans.txt`，属运行时加载的静态资源，因此把“留空表示不归档”
   改为“留空表示自动归档到下载目录下的 `completed`，目录不存在时自动创建”，
   与实现一致；`aria2SettingService` 继续用 `GET api/v1/config` 的归一化结果
   覆盖显示值，默认开启状态无需构建期常量。

7. 归档目录跟随下载目录。用户在界面修改下载目录时，若归档目录仍是
   “旧下载目录/completed”这一默认派生值（或为空），保存前用
   `syncArchiveRootWithDownload` 重新派生到新下载目录下；用户显式自定义过的
   归档目录原样保留。规则只在保存路径生效，不改动读取与安装路径，避免旧配置被
   悄悄改写。若不这样做，改完下载目录后任务会被搬回上一个目录的 `completed`，
   表现为“改了下载路径文件还跑到别处”。

## 后果

- 全新安装后即可直接下载并自动归档，无需先选择目录；代价是归档目录与下载目录
  同层可见，用户在文件管理器中会看到下载目录下的 `completed`。
- 已有配置里显式设置过的 `download_root` 与 `archive_root` 不被覆盖，
  升级只补齐缺失项，用户的自定义选择优先。
- 若用户把默认下载目录改到共享目录之外，`completed` 也随之派生到新目录，
  授权边界仍然只覆盖 `TRIM_DATA_SHARE_PATHS` 与已授权卷目录。
- 归档自愈依赖目录属主正确。生命周期脚本已负责建目录与 chown；
  手工改坏属主时表现为权限错误日志，而不是静默丢文件。
