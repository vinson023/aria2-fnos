# ADR-007：以网关、专属用户和授权目录作为安全边界

## 状态

规划阶段已接受。

## 决策

应用采用三层边界：飞牛统一网关负责会话入口，专属应用用户负责进程权限，飞牛共享/授权目录负责用户数据访问范围。Aria2 RPC 只允许管理器从回环地址访问。

## 原因

Aria2 是全局下载守护进程，能够读取任务、写入文件并执行回调。单独依赖前端隐藏配置或客户端传入的用户 ID 不能形成可靠安全边界。

## 影响

管理器必须在每次请求校验网关身份、在文件操作前验证授权根目录，并在配置或清理失败时保持旧状态。相关安全测试成为 Phase 5 至 Phase 7 的必需验收项。

## 修订（2026-11-24）

下载目录的授权口径由“必须位于 `config/resource` 声明的共享目录或 `authorized_roots`”
扩展为“飞牛数据卷（`/vol<N>`）内 + 以专属应用用户实测可写”，并把
`TRIM_DATA_ACCESSIBLE_PATHS` 纳入授权来源。原因：用户无法在应用设置里把下载目录改到
已有的共享目录（如 `/vol1/1000/downloads`），保存会被拒绝。判定仍拒绝数据卷以外的
系统路径与应用用户写不进去的目录。详见 `ADR-019-wizard-configurable-parameters.md`。
