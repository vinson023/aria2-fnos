# ADR-007：以网关、专属用户和授权目录作为安全边界

## 状态

规划阶段已接受。

## 决策

应用采用三层边界：飞牛统一网关负责会话入口，专属应用用户负责进程权限，飞牛共享/授权目录负责用户数据访问范围。Aria2 RPC 只允许管理器从回环地址访问。

## 原因

Aria2 是全局下载守护进程，能够读取任务、写入文件并执行回调。单独依赖前端隐藏配置或客户端传入的用户 ID 不能形成可靠安全边界。

## 影响

管理器必须在每次请求校验网关身份、在文件操作前验证授权根目录，并在配置或清理失败时保持旧状态。相关安全测试成为 Phase 5 至 Phase 7 的必需验收项。
