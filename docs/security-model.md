# 安全模型与控制项

## 保护目标

1. 只有经过飞牛认证且符合应用权限的用户，才能通过 Web 界面控制 Aria2。
2. RPC 密钥、配置文件、会话文件和日志不被浏览器或未授权应用读取。
3. 下载、归档和清理操作不能越出用户已授权的目录范围。
4. 端口和配置修改不会在失败时留下不可恢复的半配置状态。
5. 外部 Tracker 数据或下载任务内容不能被当作本地脚本执行。

## 威胁与控制

| 威胁 | 风险 | 设计控制 | 后续证据 |
| --- | --- | --- | --- |
| 直接访问 Aria2 RPC | 未授权控制下载、读取任务信息 | RPC 只绑定 `127.0.0.1`；外部请求只能到统一网关 | 外部地址连接失败；管理器本地请求成功 |
| 浏览器获取 RPC secret | 密钥泄露后可绕过应用鉴权 | secret 只由管理器注入 RPC；静态资源和响应不得包含 secret | 浏览器网络/资源扫描无 secret |
| 伪造用户 Header | 冒充管理员 | 只信任飞牛统一网关到 Unix Socket 的转发上下文；不接受客户端自带身份字段 | 直接访问 Socket 被禁止；伪造 Header 测试失败 |
| 路径穿越 | 读取或删除系统文件 | 规范化路径、限制在共享/授权根目录、拒绝 `..` 和符号链接逃逸 | 穿越、绝对路径和链接逃逸用例均被拒绝 |
| 清理回调误删 | 用户数据丢失 | 仅删除已确认的任务路径；完成文件不按错误状态删除；默认保守 | 错误、删除、完成任务的隔离测试 |
| 端口冲突 | 服务无法启动或覆盖其他服务 | 保存前检测范围、占用和 RPC/BT 冲突；失败时保留旧配置 | 冲突配置被拒绝；旧配置仍可启动 |
| 配置注入 | aria2 执行非预期选项或命令 | 使用结构化字段白名单生成配置；回调路径固定为包内文件 | 特殊字符和未知字段测试 |
| Tracker 供应链 | 恶意内容影响本机 | Tracker 只作为数据写入 RPC/配置，不执行响应内容；请求有超时和大小限制 | 恶意/超大/失效响应测试 |
| 外部 URL 反代 | SSRF 或内网探测 | 管理器后端目标固定为本机 aria2，拒绝用户提供 URL | 任意目标 URL 请求被拒绝 |
| 降权失败 | 服务获得过高系统权限 | FPK 使用 `run-as=package`；常驻服务禁止 root | 进程 UID/GID 与权限声明一致 |
| 日志泄露 | secret、路径或身份信息外泄 | 日志过滤密钥；错误信息最小化；敏感文件单独权限 | 日志扫描和权限检查 |

## 身份与授权边界

- 飞牛统一网关负责确认登录态，并转发 `X-Trim-Userid`、`X-Trim-Isadmin` 和
  `X-Trim-Username`。
- 管理器在每个请求上重新判断管理员权限，不把前端传入的用户 ID 当作可信身份。
- 第一版所有 Aria2 全局控制接口仅对管理员开放。
- 文件选择和下载目录设置必须经过飞牛共享目录声明或用户授权流程。

## 端口变更安全流程

1. 验证 `rpc_port` 和 `listen_port` 为允许范围内的整数。
2. 检查两个端口互不冲突，并检查系统当前占用情况。
3. 写入临时配置文件，不直接覆盖当前可用配置。
4. 如有活动任务，提示用户暂停或确认重启影响。
5. 受控停止 Aria2，启动新配置并验证 RPC 与 BT/DHT 监听。
6. 验证失败时恢复旧配置并重新启动；记录不含 secret 的错误原因。

## 安全默认值

- RPC 默认仅回环监听。
- `rpc_port=6800`、`listen_port=6888`，但均可修改。
- 自动归档、Rclone 和 PT 专用配置默认关闭或不打包。
- 卸载默认保留配置、会话和用户下载数据。
- 所有高风险操作都需要管理员权限和明确的配置/界面动作。
